| Documento | Descripción |
|---|---|

| [deployment-platforms_ES.md](./deployment-platforms_ES.md) | Instrucciones de implementación específicas de la plataforma para Coolify, Portainer, CapRover, Docker Swarm y Docker Compose genérico |
| [docker-configuration_ES.md](./docker-configuration_ES.md) | Referencia técnica para los Dockerfiles y docker-compose.yml, incluidas las etapas de compilación, verificaciones de estado (health checks) y manejo de variables en tiempo de compilación vs ejecución |

Para información general del proyecto, librerías de clientes de API y un resumen de la arquitectura, consulta el [README del proyecto](../README_ES.md).
